# Prodesk IT: Landing Page (Sprint 01)

Responsive landing page for the Prodesk IT digital marketing wing, built with **raw HTML, CSS (Flexbox + Grid) and vanilla JavaScript**.

## Features
**Phase 1 (MVP):** Flexbox navbar with hamburger menu on mobile, hero with "Get Started" CTA, 3-card CSS Grid services module, footer with social icons.
**Phase 2:** Dark/Light toggle (class on `<body>`, remembered in localStorage), hover/scale states on buttons, z-axis lift on cards, sticky navbar.
**Phase 3 (partial):** Glassmorphism navbar via `backdrop-filter`.

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Files
- `index.html`: markup
- `styles.css`: all styling (CSS variables for theming)
- `script.js`: theme toggle, mobile menu
- `Prompts.md`: AI usage log
